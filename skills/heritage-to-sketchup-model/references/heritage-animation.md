# 标记、场景与动画

首次建模或用户要求整理时，按用途约定分类。可用起点：地面台基柱础、主体木柱、梁枋铺作、檩椽角梁、望板封檐、外墙山墙、门窗封板、栏杆雕饰、屋瓦脊饰、景观。不是所有项目都需要十类。

边面保持 Untagged；分类放在群组/组件层级。混合系统组可保持 Untagged，在内部按类别赋标记；检查父子标记叠加造成的隐藏。共享定义的内部修改影响所有实例，先判断是否需要独立化。

新增构件继承正确分类。记录并比较修改前后的场景显隐、镜头、播放勾选、过渡和停留时间。用户手改设置优先，不为新增几块板重建整套场景。

区分镜头过渡、标记累积显示、构件连续运动以及输出视频叠化。不要承诺调整场景过渡秒数即可让标记对象渐显或升起。先核对当前 SU 能力及已有插件，不擅自安装动画插件。

生长展示可先用固定机位累计场景；原检查场景可保留并按用户目的退出播放。显隐动画交付时明确其表现形式。验证各阶段实际显示与最终完整模型一致，导出阶段证据；展示顺序不是经核准的施工方案。
