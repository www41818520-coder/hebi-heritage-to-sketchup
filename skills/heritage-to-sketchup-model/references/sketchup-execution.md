# SketchUp 执行与恢复

延续用户既有授权；已授权建模、局部修改或自行打开模型时，不重复询问。只读检查可用于定位目标。未被授权的关闭、丢弃修改、外部发布不由建模授权代替。

使用本目录 scripts 下的 inspect_bridge_targets.ps1 识别实际模型路径。多实例时用已知项目路径精确选择，不把唯一响应窗口或旧端口当作充分证据。无法区分时才询问用户；无标题模型核对内容与实例后记录身份。

发送代码前读修改状态。存在用户修改时保留当前内存模型并另存新版本；不能自动重载旧磁盘文件。只读模型也另存可写新路径，不覆盖原文件。

本地桥工具及参数用各脚本帮助核实；调用示例：send_su_code.ps1 -UserConfirmedBuild，自动启动工具在已有自动打开授权下使用 -UserAuthorizedAutoStart。检查本机实际依赖，不静默安装软件。

所有几何修改用事务；异常回滚。长任务先检查结果/状态，不因客户端超时重复执行。连续失败时诊断同一原因；无法安全继续则说明具体卡点，不无限重启或重放。

新增/修改脚本统一UTF-8。先验证小范围几何和目标版本，再批量执行；替换旧系统时只处理本次确认的对象，不清除用户编辑。保存后核对输出路径、文件与真实模型证据。正常用户更新使用模型名称与进度，避免端口、进程号和控制台细节。

完整图纸模式使用本目录的生产生成器和对应 finalize 脚本；效果图/局部模式保留项目专用执行脚本和专项检查，不借用另一模式的正式PASS。

## 独立运行配置

古建副本使用 su_heritage_bridge.rb、heritage_su_bridge_config.json、HeritageSketchUpBridge，以及独立的任务加载器名称。不得覆盖现代版同类插件。此隔离只完成静态校验，未验证双插件并存运行；安装前检查现有插件并按实际任务授权执行，不把创建skill当成安装授权。
